Política de Privacidad

Política de Privacidad y Protección de Datos ISO 27701

1. Responsable del tratamiento

Market Radar AI es una aplicación de uso personal para monitoreo de inversiones. El usuario que instala y opera la aplicación actúa simultáneamente como responsable del tratamiento y como interesado.

2. Datos que se tratan

  • Cartera de inversiones: ticker, número de acciones, precio medio de compra.
  • Historial de operaciones: compras, ventas, comisiones, notas personales.
  • Alertas de precio: condiciones, precios objetivo, historial de disparos.
  • Datos de mercado: precios, métricas técnicas y fundamentales (fuente: Yahoo Finance). Estos son datos públicos, no datos personales.
  • Análisis de IA: informes generados con Claude (Anthropic). Los datos de cartera se envían a la API de Anthropic para su procesamiento.
  • Suscripciones Web Push: endpoint, claves de cifrado del navegador.
  • Registro de auditoría: eventos de acceso (IP, tipo de evento, timestamp).

3. Finalidad y base jurídica

Los datos se tratan exclusivamente para el funcionamiento de la aplicación de monitoreo de inversiones. La base jurídica es el interés legítimo del propio usuario (RGPD Art. 6.1.f) al gestionar su propia cartera de valores.

4. Transferencias internacionales

Los datos de cartera (tickers, métricas) se envían a Anthropic, Inc. (USA) para la generación de informes de análisis. Anthropic actúa como encargado del tratamiento sujeto a sus términos de privacidad y las Cláusulas Contractuales Tipo de la UE.

No se realizan otras transferencias internacionales de datos personales.

6. Medidas de seguridad (ISO 27001)

  • Autenticación con contraseña bcrypt + 2FA TOTP (RFC 6238).
  • Sesiones persistentes con expiración de 30 días; contraseña con expiración a 90 días.
  • Cifrado en tránsito: HTTPS (configuración del reverse proxy), Web Push AES-GCM (RFC 8291).
  • Cabeceras de seguridad HTTP: X-Frame-Options, CSP, X-Content-Type-Options, etc.
  • Protección CSRF con token rotatorio (24 h) en todos los formularios POST.
  • Rate limiting en endpoints de autenticación y operaciones costosas.
  • Bloqueo de IP tras 5 intentos fallidos de login (15 minutos).
  • Registro de auditoría de eventos de seguridad en BD SQLite.
  • Backups automáticos diarios cifrados con AES-256-CBC.

7. Derechos del interesado (ISO 27701 Art. 9)

Como usuario y responsable del tratamiento, puedes ejercer los siguientes derechos desde la sección GDPR / Mis Datos:

  • Acceso y portabilidad: exportar todos tus datos en formato JSON.
  • Supresión (derecho al olvido): eliminar todos los datos personales de la aplicación.
  • Rectificación: editar posiciones, operaciones y alertas desde el dashboard.

8. Web Push

Las notificaciones Web Push requieren que el navegador registre una suscripción (endpoint + claves de cifrado). Estos datos se almacenan en la base de datos local y se usan exclusivamente para enviar notificaciones de la aplicación. Puedes cancelar la suscripción en cualquier momento desde la configuración del navegador o desde el dashboard.

9. Contacto

Al ser una aplicación de uso personal, el responsable del tratamiento es el propio usuario. Para cualquier cuestión técnica, consulta la documentación del proyecto.
